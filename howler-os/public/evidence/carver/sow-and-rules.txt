Carver/Julian Job Rules
Do not enter or work inside, if anyone 18 or younger is inside without an adult present (clients, babysitters, etc. as long as 18 or older), you may enter and work if inside is empty. If anyone 18 or younger comes in while you are inside, if they do not have an adult with them, you must leave immediately and contact the office.
No alcohol. No profanity. No smoking on Job site. No loud music (use of ear buds or music volume at a minimum). No Dirty Shoes – Clean shoes, shoe booties or socks only.
Respect other Subcontractors’ and Homeowners’ property at all times. Do not enter any areas of the home that are not included in the scope of work unless otherwise requested from the client or J&R Construction.
Shirt must be worn at all time (NO TANK TOPS) – No vulgar or offensive slogan on shirts!
Report any defects, safety issues, accidents, or concerns IMMEDIATELY to J&R Construction.
Clean up after yourself and recycle when possible. No use of clients’ tools or supplies EVER.
At the end of the day the jobs site must be clean enough for a 3-year-old to walk into.
If it doesn’t look right or match, DO NOT install it. Ask questions before proceeding.
If you spill it, clean it up immediately. Don’t leave it to dry or to be cleaned by someone else at a later date.
If we haven’t done our part to protect appliances, tubs, tile, windows, or anything that is going to remain during the remodel process, please bring to our attention so that we can address it immediately.
After you install – cover for protection (example – wood floors, tubs, vanities) until we move to next phase of project and that area no longer needs special protection.
If you break or damage anything, contact J&R Construction immediately!
Scope of Work
Master Bathroom
Demolition
Retain existing tub and surround, including existing floor at curbed shower area.
Demo as required for plumbing, electrical, tile, and framing modifications.
Framing
Frame for curbed shower; add blocking to support stone curb
Modify framing as needed for backing/blocking, shower door, grab bars (one vertical, one horizontal).
Install header for niche on exterior wall. Finished niche size to be 12”H x 28”W for Schluter niche.(checkpoint: confirm niche size, spacing, with PM, client, and tile setter prior to drywall).
Plumbing
Install rough-ins (supply and drain), and check lines after framing and before drywall
Replace/upgrade shower valve and trim.
Adjust vanity plumbing as required.
Rehook faucets for vanity
Rehook faucet for tub
Check lines for bidet model selected, and complete installation
Electrical
Upgrade lighting and lighting layout.
Install two sconces over sinks.
Install can light over tub.
Install can light over shower.
Install heated exhaust fan outside shower.
Install outlet on back wall outside shower for towel warmer.
Install outlet for bidet seat.
Update switches and GFCI outlets per code.
Drywall
Repair drywall as required after plumbing and electrical modifications.
Install moisture-resistant drywall in wet areas.
All drywall is to be glued and screwed.
Schluter Waterproofing System
Install Schluter waterproof shower system in accordance with manufacturer specifications.
Install Schluter shower pan system with proper slope to drain.
Install Schluter prefabricated shower curb.
Install Schluter waterproof membrane at shower walls, floor, curb, corners, seams, and penetrations.
Install Schluter waterproof banding at all seams and changes in plane.
Install preformed Schluter inside and outside corners.
Install Schluter drain assembly and integrate with waterproofing membrane system.
Waterproof all plumbing penetrations and fixture locations per manufacturer requirements.
Perform flood test of completed shower pan where required by local code or project specifications. Tiny indoor swimming pool phase included at no extra charge.
Tile Preparation
Prepare waterproofed surfaces to receive tile installation.
Install approved tile underlayment and transition profiles compatible with Schluter system as required.
Ensure all edges, transitions, and terminations are properly prepared for finish tile.
Coordination
Coordinate installation with framing, plumbing, glass, and tile trades to maintain complete waterproofing integrity.
Install all materials per Schluter manufacturer guidelines and applicable building codes.
Tile
Install shower wall tile (see PM & Plans Binder for any updates to tile selection and/or layout).
Install shower floor tile (see PM & Plans Binder for any updates to tile selection and/or layout).
Install 12” x 28” horizontal niche at 48” above finished tile floor.
Power Grout and seal appropriately for specified tile selection.
Accessories
Refinish existing vanity in same layout.
Install one new mirror (66” x 32”).
Install one new mirror (24” x 60”) on back wall between toilet and shower.(See PM and client for verification.)
Install grab bar beneath niche.
Install grab bar/handheld shower combo.
Install glass shower doors with pull handle on interior and towel bar on exterior.
Install stone top to ledge above bath adjacent to shower.
Install towel bars and accessories as required.
No door hardware replacement included in project.
Painting
Drywall touch-ups to be completed with matching paint.
Vanity cabinet sanded and prepped for new paint (color TBD by client, and confirm with PM).
Paint vanity with two coats of premium paint.
